# Сайт для бронирования ПК в киберспортивном клубе

## Структура
backend - api, написанный на FastAPI.
frontend - фронтенд на html, ajax используется для общения с api

## FastAPI
* Вход и регистрация через JWT токены
* Личный кабинет с загрузкой аватарки
* Бронирование ПК и отображение сессий
* Добавление пользовательских настроек
* Админ панель - генерация новых сессий, создание пользовательских настроек

## Redis 
* Сессии с использованием JWT токена

## JavaScript
* Классы для общения с api
* Динамическое обновление страниц
  
## Все технологии
* Fast API
* Javascript (AJAX)
* PostgreSQL
* Docker-compose
* Redis
* Locust
